# AI sidebar rework — decisions

Source of truth for the rework. Every entry here was answered explicitly; anything
not listed was left to judgement and is marked as such.

## Reasoning ("thinking")

- **Collapsible section** above the answer, headed `Thought for 4s · 2.1k tokens ·
  <first ~6 words>`. Click toggles.
- While streaming: **collapsed, with the current reasoning line running in the
  header** as a ticker. Expands to nothing on its own; the ticker just stops.
- Models that emit discrete reasoning steps (o3, Gemini) render as a **numbered
  list of steps**, not one blob.
- Plumbing: **structured field first, `<think>` fallback**. `AiMessageData` grows a
  real reasoning field that strategies write into directly; a regex pass over the
  content still catches `<think>` for local models via Ollama.
  This is the actual bug being fixed — today `<think>` reaches `MarkdownText`,
  which silently eats it as an unknown tag, so reasoning is indistinguishable from
  the answer, and `messageData.thinking` (used for colouring) is never set at all.
- Persistence (judgement call, no explicit answer): **always stored, selectively
  sent**. Replayed to the API only where the protocol requires it — Anthropic's
  signed thinking blocks with tool use, Gemini thought signatures — and stripped
  for everyone else so it doesn't burn tokens.

## Message design

- **Asymmetric**: user messages are compact bubbles on the right with a *neutral*
  background; assistant answers run full width with no bubble.
- **Icon + label** for authorship. Icons are **own redrawings** in the dots' style,
  not vendor brand files — recognisable, no trademark shipped in a GPL repo.
- Model label on **every** answer, not only when it changes.
- Action buttons (copy / regenerate / delete) appear **under the message on hover**.
- **Density toggle** in chat settings (spacious ↔ compact).
- Dividers **on events** — model switch, context compaction, mode change.
- Timestamps **on hover** only.
- Long answers render **in full**; no truncation.
- Accent colour used **liberally**; service blocks (reasoning, tools, errors) share
  one **muted background differing only by icon**.
- Font stays the dots' main font.
- Wide sidebar: **text column capped**, code and tables still full width.

## Streaming

- Text **fades in** per chunk (M3 Expressive springs elsewhere in the UI).
- Waiting for the first token: **animated dots**.
- Autoscroll **sticks to the bottom, but yields** the moment you scroll up.
- Send button **becomes a stop button** during generation.
- Typing while generating is allowed — the message **queues** and sends itself when
  the answer finishes.
- Generation **continues when the sidebar is closed**; a dot on the bar button is
  the only notification.

## Tools, modes, agentic behaviour

- Tool calls: **one compact line, expandable** to arguments and output.
- File edits: **`+N/-M` summary**, full diff on click.
- Command output: **head and tail**, with `… N lines hidden` between.
- Permission modes, cycled with **Shift+Tab and a chip next to the input**:
  `Plan` → `Default` → `Auto` (default) → `Yolo`.
- Plan mode result is a **card with Execute / Edit / Cancel**.
- Claude Code's TODO list gets a **pinned panel** above the chat.
- Auto-approved commands are marked with a **shield icon** (reason in tooltip);
  anything the guard model refuses raises a **card in the chat plus a system
  notification**.
- **MCP** support: calls rendered like any other tool, plus GUI for the server list,
  on/off switches, connection status, adding a server, and per-server tool lists.

## Sessions and persistence

- **Autosave after every answer** (and on send). Chats are **one JSON file each**,
  kept **without a cap**.
- Chat list is **both**: a slide-out panel and a quick search popup (Ctrl+K),
  searching **titles and message text**.
- `/save`, `/load`, `/new` get fixed as part of this.
- Startup always opens a **fresh empty chat**; history stays in the list.
- Titles are generated by a **cheap model** (Flash-Lite).
- Claude Code sessions are **hard-bound**: a chat remembers its session id and
  working directory and resumes into the same one.
- Unsent input is kept as a **per-chat draft**.
- Old save format may be **broken outright** — no migration required.

## Models

- Model catalogue **moves out of `Ai.qml` into JSON**, and is **refreshed from the
  provider list endpoints** where they exist.
- **Local models matter**: autodiscover a running Ollama and list its models.
- No network → **offer to switch to a local model**.
- Model picker: **groups + search + favourites**.
- Switching model mid-chat **carries the whole history** across.
- Regenerate menu can **answer with a different model**; alternatives are kept as
  **1/2 branches**, same for edited questions.

## Context

- Context bar is the **only metric always visible**; cost and speed live in its
  tooltip.
- Overflow: **ask before compacting**, never silently.

## Input

- **Growing field**, up to ~8 lines then scrolls.
- **Ctrl+Enter sends**; Enter is always a newline.
- Slash commands get **both** inline fuzzy autocomplete and a cheatsheet button —
  but every command must also be reachable from the GUI.
- Attachments: **clipboard paste, drag-and-drop, file picker, and region
  screenshot**.

## GUI parity (no command-only features)

Settings live **both** in an in-sidebar panel (frequent: model, tools, mode) and in
the settings app (rare: keys, prompts). Needed:

- **API keys** — per-provider fields, presence indicator, key test. Storage stays in
  the system **keyring**.
- **Tools and yolo** — switches for search, command execution, auto-approval.
- **System prompt** — editor plus profile picker.
- **Temperature** and **chat export**.
- **First run**: a real setup wizard — pick provider → enter key (with a link to
  where to get one) → verify → done.

## Prompt profiles

Shipped set, switchable in one click near the input: **CTF/reverse**, **Code &
Linux**, **Plain conversation**, **Terse mode**. The existing system prompt is
**rewritten from scratch** rather than kept as-is.

## System context

- Distro / kernel / hardware: **always** in the system prompt.
- Active window title and screenshots: **only on an explicit button**.
- Clipboard: button.
- **Super+Comma** grabs the current selection anywhere in the system and opens a
  **menu at the cursor**: Explain / Translate / Fix / Free-form question.

## Markdown

Real rendering required for **tables** (header, zebra, horizontal scroll),
**blockquotes**, **task lists**, **inline code and links**. LaTeX rendering stays.

## Code blocks

Keep highlighting, line numbers, copy. Add: **collapse when long**, **wrap toggle**,
**filename in the header**, **save-to-file button**.

## Sidebar shell

- **Drag-resizable in both docked and wide modes**, width remembered per mode.
- The detached window gets **finished properly** (title, remembered geometry).
- **Pin button** in the header so it survives focus loss.
- Thin **auto-hiding scrollbar**.
- Empty state: **suggestion cards**.
- Translator and anime tabs are **restyled to match**, not removed.

## Performance mode

Disables **syntax highlighting**, lowers **stream repaint frequency**, drops
**shadows and translucency**. Message animations stay.

## Engineering

- `AiChat.qml` (1736 lines) is **split into components**.
- **Full rewrite** is sanctioned, in stages, each stage deployable.
- UI stays **English** (translatable via `Translation.tr`).
- **Debug logging of API traffic to a file behind a flag.**

### Testing

`harness.qml` renders block widgets offscreen to a PNG, so a change can be
checked without restarting the shell:

    HARNESS_OUT=/tmp/blocks.png qs -p ~/.config/quickshell/flash-impulse/harness.qml

Never `qs -c flash-impulse kill` while the screen is locked — it kills the lockscreen and
drops Hyprland into a fallback only clearable from a TTY. Check first with
`qs -c flash-impulse ipc call lock status`.
